# NoaOS

A personal operating system for being Noa.

NoaOS is a Hebrew-first, RTL-first web app that holds the different parts of one person's life — today, tasks, health, work, captures, reflection — in one system, centered on **Today**. It is built for exactly one user. It is not a productivity product.

> **Status:** v0.1 planning. Documentation foundation only — no application code yet.

## Running locally

Not yet scaffolded. Planned stack: Vite + React + TypeScript (see [docs/TECH_ARCHITECTURE.md](docs/TECH_ARCHITECTURE.md)).

## Data & privacy

In v0.1 all data lives only in the browser on the device you use (primarily Chrome on Mac). There is no server, no account and no sync. Use **Settings → Export** to back up. This repository is public: it contains code only, never personal data.
